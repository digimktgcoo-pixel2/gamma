Accessibility

Accessible to Everyone.
No Exceptions.

In an emergency, everyone deserves equal access to life-saving information. NuclearThreatWatch.org is committed to meeting WCAG 2.1 Level AA accessibility standards so that real-time radiation data is available to every user, regardless of ability or the technology they use to access it.

Last reviewed: March 2026

Our Accessibility Commitment

NuclearThreatWatch.org is operated by DigiMktg Co. LLC. We believe that access to real-time nuclear threat and radiation monitoring data is a public safety issue — and public safety tools must work for everyone. We are actively working to ensure that NuclearThreatWatch.org conforms to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA, as published by the World Wide Web Consortium (W3C).

This commitment is ongoing. We review and update accessibility features with each significant site update and welcome direct feedback from users who encounter barriers while using our tools.

Measures We Have Taken

We have implemented the following accessibility measures across NuclearThreatWatch.org:

  • Semantic HTML5 structure — All pages use proper heading hierarchy (H1–H3), landmark regions (main, nav, footer), and ARIA labels on interactive components.
  • Keyboard navigation — All interactive elements including map filters, station search, and navigation links are reachable and operable via keyboard alone.
  • Screen reader support — Map visualizations include descriptive aria-label attributes. Station data cards are structured with role and label markup. The live alert ticker is marked with role="marquee" and an accessible label.
  • Color contrast — Text and interactive elements meet or exceed the WCAG 2.1 AA minimum contrast ratio of 4.5:1 against their backgrounds.
  • Text resizing — The site uses relative font sizing (rem/clamp) that responds correctly when browser text size is increased up to 200%.
  • Focus indicators — Keyboard focus is visually indicated on all interactive elements.
  • Alt text — All meaningful images include descriptive alt attributes. Decorative images use empty alt attributes to be ignored by assistive technology.
  • Progressive Web App (PWA) — The installable PWA version of NuclearThreatWatch.org provides a consistent, accessible experience on both iOS and Android devices, including compatibility with VoiceOver and TalkBack.
  • No auto-playing media — No audio or video plays automatically on any page.
  • Link context — All links are written to be descriptive and meaningful when read out of context by a screen reader.

Current Conformance Status

NuclearThreatWatch.org is partially conformant with WCAG 2.1 Level AA. Partially conformant means that some parts of the content do not fully conform to the accessibility standard. Known areas of partial conformance are listed below.

Feature Status Notes
Page structure & headings Conformant Proper H1–H3 hierarchy on all pages.
Keyboard navigation Conformant All controls reachable and operable by keyboard.
Color contrast Conformant Minimum 4.5:1 ratio on body text; 3:1 on large text.
SVG radiation map Partial Map has an ARIA label and role. Individual station data points are accessible via the station grid below the map. Full interactive SVG accessibility for screen readers is in progress.
Live data updates Partial Station cards update dynamically. ARIA live region announcements for automatic data refreshes are planned for a future update.
Alt text on all images Conformant All content images carry descriptive alt text.
Third-party ad content Partial Google AdSense and Amazon affiliate content is served by third parties. We cannot fully control the accessibility of third-party ad units.
Mobile / touch accessibility Conformant Touch targets meet minimum 44×44px size. Compatible with iOS VoiceOver and Android TalkBack.

Known Limitations

We are transparent about the areas where NuclearThreatWatch.org does not yet fully meet WCAG 2.1 AA. We are actively working to resolve the following:

  • SVG map interactivity for screen readers — The live radiation map is an SVG element. While it carries a descriptive ARIA label, individual station data points within the SVG are not fully announced by all screen readers. Users who rely on screen readers can access the same station data in the station grid section below the map, which is fully accessible.
  • Dynamic content ARIA announcements — When station data updates automatically, the changes are not currently announced via aria-live regions. This is scheduled for a future release.
  • Third-party embedded content — Google AdSense units and Amazon affiliate links are served through third-party scripts. We cannot guarantee full accessibility compliance for content generated by these platforms.

Technical Specifications

NuclearThreatWatch.org is built with the following technologies that affect accessibility:

  • HTML5 with semantic landmark elements
  • CSS3 with relative units and responsive layout
  • Vanilla JavaScript ES modules (no accessibility-blocking frameworks)
  • SVG for the radiation monitoring map
  • Progressive Web App (PWA) with manifest.json and service worker
  • Cloudflare Workers for the EPA RadNet data proxy

We rely on the following assistive technologies for compatibility testing: NVDA with Chrome (Windows), VoiceOver with Safari (macOS and iOS), TalkBack with Chrome (Android), and keyboard-only navigation in all major browsers.
